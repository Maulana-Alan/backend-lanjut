# Praktikum Backend Lanjut

Repository tugas praktikum Pemrograman Backend Lanjut menggunakan Go dan Fiber.

## Struktur Folder

- `latihan-fiber/` — Project Hello World dengan Fiber v2
- `latihan-sintaks/` — Latihan sintaks Go (variabel, pointer, struct)

## Cara Menjalankan

```bash
# Hello World Fiber
cd latihan-fiber
go run main.go
# Buka http://localhost:3000

# Tugas sintaks
cd latihan-sintaks
go run tugas2.go
go run tugas3.go
go run tugas4.go
```

## Tech Stack

- Go 1.26.5
- Fiber v2
